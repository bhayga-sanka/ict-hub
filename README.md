# ICT HUB — Student Portal

Minimal student portal prototype. Planned features: Firebase student login, online MCQ papers with automatic marking, individual student QR codes, and teacher-side QR attendance scanning.

## Current status
Frontend preview files are being added. Login and registration are demo-only and are not secure or persistent. Do not use real passwords until Firebase Authentication is connected.

## Planned stack
- HTML, CSS, JavaScript
- Firebase Authentication and Firestore
- GitHub Pages hosting
- Browser-based QR scanner

Firebase free-plan quotas apply. Production use requires secure Firestore rules and teacher/admin access controls.
